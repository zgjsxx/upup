# 2026-11-06

## 起一会 UpUp — 久坐提醒桌面应用（从零实现）

**需求来源**：用户提供完整 PRD（V1.0 MVP），要求实现可实际运行的桌面应用，而非静态 UI。

**技术选型变更**：最初按 PRD 推荐搭了 Tauri 2 骨架，用户明确提出「希望做跨端的，electron 可以吗」→ 改用 **Electron 33**。理由：跨端场景下只需 Node 环境，Win/macOS/Linux 一条命令出包，无需各平台 Rust + C++ 工具链。Tauri 骨架已移除。

### 架构要点

- **主进程** `src/main/`：`engine.ts` 纯逻辑状态机（无 Electron 依赖，可单测）、`windows.ts` 双窗口、`tray.ts` 托盘、`autostart.ts` 跨平台自启、`store.ts` 原子 JSON 持久化。
- **渲染进程** `src/renderer/`：`main.tsx`（主窗口）+ `reminder.tsx`（提醒浮窗，独立 HTML 入口）。
- **共享层** `src/shared/`：types / defaults / time（时段计算）/ ipc 通道常量。
- 状态机：`working → reminding → moving → working`，独立 `paused` / `offduty`。全部基于真实时间戳差值推进，不依赖 setInterval 累加。

### 踩过的坑（重要）

1. **`ELECTRON_RUN_AS_NODE=1` 环境变量**：本机 shell 注入了该变量，导致 Electron 以纯 Node 模式启动、`app` 为 undefined。所有启动脚本（dev.mjs / verify.mjs）必须 `delete env.ELECTRON_RUN_AS_NODE`。**打包后的 exe 直接运行时也受此影响**，需 `env -u ELECTRON_RUN_AS_NODE`。
2. **Vite 多入口白屏**：`index.html` + `reminder.html` 同时构建时，第二个 HTML 只拿到部分 chunk，缺 React 依赖导致白屏。解决：`UPUP_PAGE=main|reminder` 分两次构建，各自自包含（`scripts/build.mjs` + `vite.config.ts`）。
3. **提醒窗样式缺失**：`reminder.tsx` 起初未 `import "./styles.css"`，且只 export 组件未 `createRoot` 挂载 → 双问题导致空白。两个都要有。
4. **百分比高度柱状图塌陷**：父容器 auto 高度时 `height: X%` 无法解析，改用像素值。
5. **electron-builder Windows 符号链接失败**：winCodeSign 包里 darwin 的 .dylib 是符号链接，普通用户无权限创建 → 生成 0 字节文件 → 打包失败。解决：`scripts/fix-builder-cache.mjs` 用实体文件覆盖（这些 .dylib 仅 macOS 签名用，Windows 打包不需要）。另外打包命令可加 `--config.win.signAndEditExecutable=false` 彻底跳过。
6. **npm 官方源极慢**（单请求 50s）→ 项目内 `.npmrc` 固定 `registry.npmmirror.com` + electron 镜像。

### 验证方式（可复用）

- `npx tsx scripts/test-engine.mjs` — 53 项状态机单测（计时触发、休眠觉醒、时钟回拨、暂停、跳过、幂等统计、连续天数、裁剪）。全绿。
- `node scripts/verify.mjs` — CDP 驱动真实应用截图 + 控制台错误检查，10 个场景。全绿。
- `node scripts/verify-packaged.mjs` — 验证打包后 exe 的 preload/渲染/提醒窗。全绿。
