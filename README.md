# 起一会 UpUp

> 轻量级久坐提醒工具 · 到点温柔提醒你起身活动

一款极简、治愈的桌面久坐提醒应用。基于真实时间戳计时，支持系统托盘后台常驻、桌面通知、活动倒计时与每日习惯统计。所有数据仅保存在本机，完全离线运行。

---

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式（热更新）
npm run dev

# 构建生产包并本地运行
npm start

# 打包安装程序（输出统一到 release/，打包前自动清理旧产物）
npm run dist:win     # Windows: NSIS 安装包 + 便携版
npm run dist:mac     # macOS: DMG + ZIP（x64 / arm64）
npm run dist:linux   # Linux: AppImage + deb

# 只打目录版（不生成安装包，便于快速验证）
npm run dist:dir

# 手动清理打包产物
npm run clean
```

> 环境要求：Node.js ≥ 20。无需 Rust 或其他编译工具链，Windows / macOS / Linux 均可直接构建。

### 目录约定

| 目录 | 用途 | 是否提交 |
|---|---|---|
| `src/` | 源码 | ✅ |
| `dist/` | 前端构建产物 | ❌ |
| `dist-electron/` | 主进程 / 预加载构建产物 | ❌ |
| `release/` | **唯一的打包输出目录** | ❌ |
| `_shots/` | 自动化验证截图 | ❌ |

打包产物只会出现在 `release/`。`npm run dist:*` 会先执行 `scripts/clean-output.mjs` 清空旧产物，避免残留文件导致打包失败或产生多份难以分辨的副本。

## 功能一览

### 核心（P0）

| 功能 | 说明 |
|---|---|
| 久坐定时提醒 | 默认 45 分钟，可选 20/30/45/60/90 或自定义（1–480 分钟） |
| 多通道提醒 | 应用内悬浮卡片 + 系统桌面通知 + 可选提示音 |
| 提醒操作 | 开始活动 / N 分钟后提醒 / 跳过本次 / 关闭卡片（按设置稍后提醒） |
| 活动倒计时 | 默认 3 分钟，可选 1/3/5/10，支持提前完成或放弃 |
| 系统托盘 | 实时倒计时、立即活动、暂停/恢复、重置、设置、退出 |
| 本地设置持久化 | 原子写入 JSON，崩溃不损坏配置 |

### 体验（P1）

- **专注 / 暂停模式**：15 分钟、30 分钟、1 小时、2 小时，或暂停至手动恢复；到期自动恢复。
- **工作时间**：自定义工作日与时段（支持跨夜，如 22:00–06:00），时段外自动休眠。
- **活动统计**：今日完成次数、累计分钟数、跳过次数、最近 7 天趋势、连续达成天数。
- 开机启动、深浅色主题、减少动画。

### 趣味（P2）

- 8 组随机提醒文案 + 6 种活动建议，避免重复枯燥。
- 活动完成的柔和庆祝动效与四音琶音提示音（WebAudio 合成，无音频文件）。

## 计时设计

计时**不依赖** `setInterval` 累加，而是以真实时间戳差值推进状态机，因此能正确处理各种边界情况。

### 状态机

```
        ┌──────────── 完成活动 ────────────┐
        ↓                                  │
   [WORKING] ──到达间隔──> [REMINDING] ──开始活动──> [MOVING]
        │                        │
        │                        ├── 稍后提醒 ──> WORKING（带 snooze）
        │                        └── 跳过本次 ──> WORKING（重置计时）
        │
        └── 暂停 ──> [PAUSED] ──到期/手动恢复──> WORKING
                         
   非工作时段 ⇄ [OFF_DUTY]（不计时、不提醒）
```

### 边界处理

| 场景 | 策略 |
|---|---|
| 应用最小化 / 后台 | 计时在主进程进行，不受渲染进程节流影响 |
| 系统休眠 | 单次 tick 间隔 > 30 秒视为休眠，**该段时间不计入工作时长**；唤醒后从 0 重新计时，避免集中弹出过期通知 |
| 应用重启 | 阶段与 `lastTick` 落盘；重启时按实际经过时间校正，过期提醒不恢复 |
| 系统时间回拨 | 负差值按 0 处理；回拨超过 5 分钟则重新对齐，不累计也不倒退 |
| 工作时间结束 | 自动进入 `OFF_DUTY`，关闭已弹出的提醒 |
| 通知被忽略 | 提醒卡片保持显示，同一时刻只存在一个提醒；系统托盘持续显示「该起身活动啦」 |
| 修改间隔 | 缩短后若已超时则立即提醒（不叠加）；延长则从当前进度继续 |

### 防重复统计

完成活动统一走 `completeMove()`，且只有 `moving` 状态可触发。关闭窗口、重复点击、多次调用均不会重复记录完成次数。

## 技术栈

| 模块 | 选型 |
|---|---|
| 桌面框架 | **Electron 33** |
| 前端 | React 18 + TypeScript |
| 构建 | Vite 6（渲染进程）+ esbuild（主进程/预加载） |
| 样式 | Tailwind CSS 3 + CSS 变量主题 |
| 图标 | Lucide React |
| 存储 | 原子写入的本地 JSON（`userData` 目录） |
| 打包 | electron-builder（NSIS / DMG / AppImage / deb） |

### 为什么选 Electron 而不是 Tauri

跨端场景下 Electron 更省心：只需 Node 环境，Windows / macOS / Linux 一条命令出包，不必为每个平台准备 Rust + C++ 工具链（macOS 需 Xcode、Linux 需 webkit2gtk）。代价是包体积较大（约 90–150 MB），换来的是构建与调试体验的稳定性。

## 数据存储

所有数据保存在系统 `userData` 目录，不上传任何服务器：

| 平台 | 路径 |
|---|---|
| Windows | `%APPDATA%\起一会\` |
| macOS | `~/Library/Application Support/起一会/` |
| Linux | `~/.config/起一会/` |

| 文件 | 内容 |
|---|---|
| `settings.json` | 全部偏好设置 |
| `state.json` | 计时状态（阶段、进度、截止时间） |
| `stats.json` | 每日活动记录（自动保留最近 120 天） |

写入采用「临时文件 → fsync → rename」，避免断电导致文件损坏；解析失败时自动备份为 `.broken-<时间戳>` 并回退默认值。设置页提供「打开目录」与「清空统计」。

## 测试

```bash
# 状态机单元测试（53 项，覆盖休眠、时钟回拨、暂停、幂等统计等）
npx tsx scripts/test-engine.mjs

# 界面自动化验证（启动应用 + CDP 截图 + 控制台错误检查）
node scripts/verify.mjs
```

`verify.mjs` 会依次验证：首页渲染、深色主题、设置页、统计页、提醒触发、提醒卡片、活动完成、暂停恢复、配置持久化，并将截图输出到 `_shots/`。

## 隐私与无障碍

- 无需注册登录，不收集任何个人信息，不含广告与行为追踪。
- 计时与提醒完全离线，不依赖网络。
- 提醒窗使用 `showInactive` 弹出，**不抢占键盘焦点**，不打断全屏演示或游戏。
- 支持键盘操作：提醒卡片 `Enter` 开始活动、`Esc` 关闭；所有按钮有可见焦点环。
- 支持「减少动画」，并自动遵循系统 `prefers-reduced-motion`。
